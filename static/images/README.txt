Tips:
- Square photos look best (the squares are square). Crop them roughly square.
- .jpg works too — just change the file name in static/game.js
  (e.g. "memory1.png" -> "memory1.jpg") to match.
- Until a photo exists, the square shows a cute "ADD PHOTO" placeholder,
  so the game runs fine even before you add anything.

The caption under each photo is set in static/game.js (the CONFIG block at the top).
